## 儿童发展评估系统测试计划

### 1. 项目概述
- **系统名称**：儿童发展评估系统
- **技术栈**：LangGraph + FastAPI + React + TypeScript
- **核心功能**：儿童发展评估、运动计划评分、科学依据检索、报告生成

### 2. 测试目标
1. 验证系统各个 Agent 节点的功能正确性
2. 测试 API 接口的稳定性和可靠性
3. 验证 RAG 知识库检索功能
4. 测试整个评估流程的完整性
5. 确保前端应用的用户体验

### 3. 测试策略

#### 3.1 测试层次
- **单元测试**：测试各个 Agent 节点的核心逻辑
- **集成测试**：测试节点间的协作和 API 接口
- **端到端测试**：测试完整的用户流程
- **性能测试**：评估系统响应时间和资源使用

#### 3.2 测试方法
- **自动化测试**：使用 pytest (后端) 和 React Testing Library (前端)
- **手动测试**：验证用户交互和报告质量
- **接口测试**：使用 Postman 或 curl 进行 API 测试

### 4. 测试范围

#### 4.1 后端测试 (FastAPI + LangGraph)

##### 4.1.1 单元测试
- `test_agent_nodes.py`：测试各个 Agent 节点的核心逻辑
  - PreprocessingNode：验证上下文压缩功能
  - ValidationNode：测试数据校验规则
  - AssessmentNode：评估儿童发展状态识别
  - RetrievalNode：测试 RAG 检索功能
  - ScoringNode：验证评分算法
  - ReportingNode：测试报告生成

- `test_schemas.py`：测试 Pydantic 数据模型验证
- `test_rag_service.py`：测试知识库检索服务
- `test_config.py`：测试配置加载

##### 4.1.2 集成测试
- `test_api_endpoints.py`：测试 API 接口
  - GET /health：健康检查
  - POST /assess：评估接口
- `test_workflow.py`：测试完整的 LangGraph 工作流

#### 4.2 前端测试 (React)
- `test_assessment_form.tsx`：测试评估表单组件
- `test_report_viewer.tsx`：测试报告查看组件
- `test_api_client.ts`：测试 API 客户端
- `test_hooks.ts`：测试自定义 React Hooks

#### 4.3 端到端测试
- 使用 Playwright 或 Cypress 测试完整的用户流程
- 模拟用户提交儿童信息和运动计划，验证报告生成
