## 目标

## 方案设计

```
├── ReviewDrawer.tsx             # 抽屉容器
├── ReviewItem.tsx               # 单个审查项
├── ImpactPreview.tsx            # 变更影响预览
└── types.ts                     # 类型定义
```

### 交互流程

```
用户点击"采纳" → 加入已采纳列表（不生效）
     ↓
用户点击"审查已采纳项" → 展开抽屉式审查面板
     ↓
面板展示所有已采纳修改的完整 diff
     ↓
支持自定义调整建议值、移除单项
     ↓
用户点击"保存为新版本" → 触发原子保存事务
```

### 核心特性

1. **抽屉式展示**: 从右侧滑出，覆盖 40% 屏幕宽度（最小 480px）
2. **自定义值输入**: 配置项支持输入自定义值，不局限于建议值
3. **单项移除**: 每个审查项支持 [移除] 按钮，从已采纳列表中移除
4. **变更影响预览**: 底部汇总展示所有变更的预期指标变化
5. **保存触发**: [保存为新版本] 按钮调用原子保存 API
