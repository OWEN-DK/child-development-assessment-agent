# Phase 8: 配置管理优化 — 总览

> **需求来源**: spec 文档 `08-config-management-overview.md`, `08a-config-metadata.md`, `08b-config-frontend-pages.md`, `08c-config-validation.md`
> **需求点数量**: 8 个
> **优先级**: P2

## 目标

优化配置管理，实现中文说明、分组展示、实时校验、冲突检测。

## 需求点清单

### 配置元数据 (1 个) - P0 基础

| # | 需求点 | 实施文件 | 优先级 | 说明 |
|---|--------|---------|--------|------|
| 1 | 配置元数据中文补充 | `01-config-metadata-chinese.md` | P0 | 所有配置项新增 name_zh, description_zh, 取值范围, 推荐范围 |

## 验收标准

- [ ] 配置主页按功能域分组展示
- [ ] 所有配置项有中文名称和用途说明
- [ ] 输入时实时校验取值范围
- [ ] 修改时展示影响范围和重载方式
- [ ] 配置版本管理功能正常
- [ ] 配置校验引擎正确执行
- [ ] 配置冲突检测正确

## 配置分组

| 分组 | 包含配置 |
|------|---------|
| RAG 检索配置 | BM25 权重、向量权重、融合模式、重排序、查询路由、年龄过滤 |
| RAG 分块配置 | PDF 分块大小、语义分割器、分块重叠 |
| LLM 模型配置 | 凭证管理、场景配置、定价配置 |
| 数据库配置 | 连接池配置、慢查询阈值 |
| Redis 配置 | 连接配置、缓存配置 |
| 日志配置 | 日志级别、日志格式 |
| 业务规则配置 | 发展领域、年龄模式、难度阈值 |
