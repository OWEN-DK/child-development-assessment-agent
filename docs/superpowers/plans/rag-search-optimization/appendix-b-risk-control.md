# 风险控制与回滚策略

## 风险评估

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|----------|
| Phase A 数据模型变更导致前端不兼容 | 低 | 中 | `age_fit_score` 默认值 0.0 保持向后兼容 |
| 年龄适配度连续值计算复杂度过高 | 中 | 中 | 添加 Redis 缓存，限制单次计算耗时 ≤5ms |
| 分数校准改动导致排序倒置 | 中 | 高 | 保留 `rag_score_method=legacy` 回滚开关 |
| 年龄过滤过严导致结果过少 | 中 | 高 | 提供严格/宽松模式切换 (`rag_age_filter_mode`) |
| Cross-Encoder 预热占用启动时间 | 低 | 低 | 后台异步预热，不阻塞服务启动 |
| MinHash 去重误判 | 低 | 中 | 调高 MinHash 相似度阈值，保留 hash 精确去重 |
| Phase C 领域词典覆盖不足 | 中 | 中 | 初始覆盖 30+ 词条，通过日志持续优化 |
| Phase C 验证规则过严误拒有效词 | 低 | 高 | 白名单优先 + 可调阈值 + legacy 回滚 |
| Phase C 本地兜底词典规模不足 | 低 | 中 | 初始 5 大领域 30 词条，动态扩展 |

## 回滚策略

| Phase | 回滚配置项 | 回滚效果 |
|-------|------------|----------|
| Phase A | `rag_score_method=legacy` | 恢复旧版混合分数计算（`relevance_score` 包含年龄适配度） |
| Phase B | `rag_weight_strategy=fixed` | 恢复固定权重 (BM25=0.5, Vector=0.5) |
| Phase C | `rag_query_rewrite_method=legacy` | 恢复旧版查询重写与同义词扩展 |
| Phase D | `rag_performance_optimizations=false` | 禁用模型预热、hash 去重、动态 initial_k |

## 灰度发布建议

1. **Phase A**: 先在内网环境验证分数分离正确性，再灰度到生产环境 10% 流量
2. **Phase B**: 调参类变更，可直接全量发布，保留回滚开关
3. **Phase C**: 同义词扩展质量验证通过后全量发布
4. **Phase D**: 性能优化类变更，可先开启预热和 hash 去重，再开启 MinHash

## 监控指标

| 指标 | 告警阈值 | 监控方式 |
|------|----------|----------|
| Precision@5 | <0.70 | 诊断测试定期运行 |
| 年龄过滤准确率 | <85% | 诊断测试定期运行 |
| P50 响应时间 | >400ms | APM 监控 |
| P95 响应时间 | >600ms | APM 监控 |
| 错误率 | >1% | 日志监控 |
| Cross-Encoder 加载失败 | >0 | 健康检查 |
