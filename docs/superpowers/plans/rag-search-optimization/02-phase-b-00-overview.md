# Phase B: 查询权重调优 (P1)

> **优先级**: P1 (调参，可独立验证)
> **对应需求**: 4.4 (查询权重动态调整)
> **对应测试**: 测试 4

## 🎯 目标

解决查询权重分配不合理问题：
- 当前所有查询使用固定权重 (BM25=0.5, Vector=0.5)
- 短查询应偏重向量检索，专业术语应偏重 BM25 精确匹配
- 现有动态权重逻辑不适配中文场景

## 📋 实施步骤

- [ ] **B-1: 查询类型分析器**
  - 详见 [02-phase-b-01-query-analyzer.md](./02-phase-b-01-query-analyzer.md)
- [ ] **B-2: 动态权重决策逻辑**
  - 详见 [02-phase-b-02-weight-decision.md](./02-phase-b-02-weight-decision.md)

## ✅ 验收标准

| 查询类型 | 当前权重 | 目标权重 |
|----------|----------|----------|
| 短查询 (<5 字) | BM25=0.5, Vector=0.5 | BM25=0.3, Vector=0.7 |
| 专业术语查询 | BM25=0.5, Vector=0.5 | BM25=0.7, Vector=0.3 |

## 🔧 回滚策略

配置项 `rag_weight_strategy=fixed` 可恢复固定权重。
