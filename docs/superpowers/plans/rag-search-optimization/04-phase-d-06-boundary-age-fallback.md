# D-6: 边界年龄映射与降级策略

> **所属 Phase**: Phase D (P2)
> **任务类型**: 单一任务 — 年龄边界映射（0 岁、18 岁）与无结果降级
> **对应问题**: 测试 10 部分问题（年龄边界查询、无结果查询未处理）

## 🎯 目标

处理年龄边界场景（0 岁婴儿、18 岁青少年）和无结果查询场景，确保系统返回合理结果而非空响应或错误。

## 📋 实施步骤

- [ ] **Step 1: 分析现有年龄边界处理**
  - [ ] 阅读 `src/core/age_filter.py` 确认年龄边界处理逻辑
  - [ ] 确认 0 岁、18 岁等边界年龄是否被正确映射到发展阶段

- [ ] **Step 2: 实现年龄边界映射**
  - [ ] 定义年龄到发展阶段的映射：
    - 0 岁 → 婴儿期（0-1 岁）
    - 1-2 岁 → 幼儿期
    - 3-5 岁 → 学龄前期
    - 6-12 岁 → 学龄期
    - 13-18 岁 → 青少年期
  - [ ] 边界年龄自动映射到最近的发展阶段
  - [ ] 0 岁用户查询返回婴儿相关内容
  - [ ] 18 岁用户查询返回青少年相关内容

- [ ] **Step 3: 实现无结果降级策略**
  - [ ] 当检索结果为空时，执行降级策略：
    - 降级 1: 放宽年龄过滤（严格→宽松）
    - 降级 2: 降低分数阈值
    - 降级 3: 返回最相关的通用内容（如"儿童发展指南"）
  - [ ] 每次降级记录日志，便于调试
  - [ ] 前端展示降级提示（如"未找到精确匹配，以下为相关内容"）

- [ ] **Step 4: 编写单元测试**
  - [ ] 测试 0 岁用户返回婴儿相关内容
  - [ ] 测试 18 岁用户返回青少年相关内容
  - [ ] 测试无结果查询触发降级策略
  - [ ] 测试降级后仍无结果返回空列表

- [ ] **Step 5: 集成验证**
  - [ ] 运行 `tests/diagnose_rag_comprehensive_v2.py` 测试 10 年龄边界场景
  - [ ] 确认降级策略合理触发

## ✅ 验收标准

| 场景 | 查询 | 年龄 | 期望行为 |
|------|------|------|----------|
| 年龄边界 (0 岁) | "婴儿训练方法" | 0 | 返回婴儿相关内容 |
| 年龄边界 (18 岁) | "青少年训练方法" | 18 | 返回青少年相关内容 |
| 无结果查询 | "量子物理儿童训练" | 5 | 触发降级策略，返回最相关内容或空结果 |

- 边界年龄正确映射到发展阶段
- 无结果查询有合理的降级策略
- 降级过程有日志记录
