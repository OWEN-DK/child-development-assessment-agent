# 07b - 提示词前端页面重构

> **本文档包含**: 提示词管理前端页面设计、交互流程、组件结构

---

## 1. 前端路由

| 路由 | 说明 |
|------|------|
| `/prompt-management` | 提示词列表页 |
| `/prompt-management/:key` | 提示词编辑页 |
| `/prompt-management/:key/versions` | 版本管理页 |
| `/prompt-management/:key/sandbox` | 测试沙箱页 |

---

## 2. 提示词列表页

### 2.1 页面布局

表格展示所有提示词，包含以下列：
- 状态（已启用且被引用/已启用但未引用/已禁用）
- 中文名称
- Prompt Key
- 分类标签
- 当前版本号 + 最后修改时间
- 操作按钮组（编辑、版本管理、测试沙箱）

顶部支持：
- 分类筛选：全部/RAG 检索/评估/评分/报告/测试用例生成
- 搜索框：支持中文名称、prompt_key 模糊搜索
- 状态筛选：全部/已启用/已禁用/未引用

### 2.2 表格列定义

| 列 | 字段 | 说明 |
|----|------|------|
| 状态 | `is_active` + `code_references` | 绿色=启用且被引用，黄色=启用但未引用，红色=禁用 |
| 中文名称 | `name_zh` | 提示词中文名称 |
| Prompt Key | `prompt_key` | 唯一标识符 |
| 分类 | `category` | 分类标签 |
| 当前版本 | 最新 `PromptVersion.version` + `created_at` | 版本号 + 最后修改时间 |
| 操作 | 按钮组 | 编辑、版本管理、测试沙箱 |

### 2.3 搜索与筛选

| 功能 | 说明 |
|------|------|
| 搜索框 | 支持中文名称、prompt_key 模糊搜索 |
| 分类筛选 | 按 `category` 分组筛选 |
| 状态筛选 | 全部/已启用/已禁用/未引用 |

## 3. 提示词编辑页

### 3.1 页面布局

左右分栏布局：
- **左侧**：基本信息（中文名称、用途说明、分类）、提示词内容编辑器、版本变更说明、保存按钮
- **右侧**：变量面板（自动提取的变量列表，点击可插入到编辑器光标处）、影响分析面板（变量变更、代码引用数量、配置依赖变化）

### 3.2 交互流程

1. 用户进入编辑页，加载提示词元数据 + 最新版本内容
2. 用户修改内容，系统实时提取变量（自动检测 `{variable}` 格式）
3. 用户点击"保存为新版本"
4. 前端校验：
   - 变量是否与 variables_schema 匹配
   - 是否删除了必填变量
   - 是否新增了未声明变量
5. 如果校验失败：弹出警告框，展示不匹配的变量列表，用户可选择"强制保存"或"取消修改"
6. 如果校验通过：调用 API 保存新版本，跳转到版本管理页

### 3.3 变量校验规则

| 校验项 | 规则 | 处理方式 |
|--------|------|---------|
| **变量缺失** | 内容中缺少 `variables_schema` 中标记为 `required: true` 的变量 | 警告，允许强制保存 |
| **变量多余** | 内容中包含 `variables_schema` 中未声明的变量 | 警告，提示用户更新 schema |
| **变量类型不匹配** | 变量格式与声明类型不符 | 警告，允许强制保存 |

---

## 4. 版本管理页

### 4.1 版本列表

表格展示所有版本，包含：选择框、版本号、修改人、修改时间、描述。
底部操作：对比选中版本、回滚到此版本。

### 4.2 版本对比

左右分栏对比两个版本的内容差异，底部展示变更摘要：
- 新增变量列表
- 删除变量列表
- 内容变化行数

---

## 5. 测试沙箱页

### 5.1 页面布局

左右分栏布局：
- **左侧**：输入变量表单（根据 variables_schema 自动生成）、运行测试按钮、历史测试记录列表
- **右侧**：输出预览区（展示当前版本 LLM 输出）、对比模式开关（可开启新旧版本输出对比）、复制输出/导出对比按钮

### 5.2 交互流程

1. 用户进入测试沙箱页，加载 variables_schema，生成输入表单
2. 用户填写变量值
3. 点击"运行测试"，调用 API 传入变量
4. 展示 LLM 输出结果
5. 用户可开启"对比模式"，选择旧版本，展示新旧版本输出差异

## 6. API 端点

### 6.0 删除的老 API 端点

以下现有 API 端点直接删除，不做任何兼容：

| 方法 | 路径 | 删除原因 |
|------|------|---------|
| GET | `/api/v1/prompts/ab-tests` | A/B 测试功能删除 |
| POST | `/api/v1/prompts/ab-tests` | A/B 测试功能删除 |
| POST | `/api/v1/prompts/ab-tests/{test_id}/toggle` | A/B 测试功能删除 |
| GET | `/api/v1/prompts/{prompt_key}` | 原端点返回 A/B 测试参数，改为新端点 `/api/v1/prompts/metadata/:key` |

### 6.1 提示词元数据

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/prompts/metadata` | 获取所有提示词元数据列表 |
| GET | `/api/v1/prompts/metadata/:key` | 获取单个提示词元数据 |
| PUT | `/api/v1/prompts/metadata/:key` | 更新提示词元数据 |

### 6.2 提示词版本

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/prompts/:key/versions` | 获取提示词版本列表 |
| GET | `/api/v1/prompts/:key/versions/:version` | 获取指定版本详情 |
| POST | `/api/v1/prompts/:key/versions` | 创建新版本 |
| GET | `/api/v1/prompts/:key/versions/:v1/compare/:v2` | 对比两个版本 |
| POST | `/api/v1/prompts/:key/versions/:version/rollback` | 回滚到指定版本 |

### 6.3 测试沙箱

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/v1/prompts/:key/test` | 运行测试沙箱 |

### 6.4 影响分析

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/prompts/:key/impact` | 获取影响分析结果 |
| POST | `/api/v1/prompts/:key/scan` | 手动触发代码引用扫描 |
