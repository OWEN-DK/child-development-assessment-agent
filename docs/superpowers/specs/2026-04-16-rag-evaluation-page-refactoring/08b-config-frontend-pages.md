# 08b - 前端配置页重构

> **本文档包含**: 系统配置前端页面重构设计、分组展示、实时校验、影响范围展示

---

## 1. 前端路由

| 路由 | 说明 |
|------|------|
| `/system-config` | 系统配置主页（分组列表） |
| `/system-config/:category` | 分类配置页 |
| `/system-config/:category/:key` | 单个配置编辑页 |

---

## 2. 系统配置主页

### 2.1 页面布局

卡片网格布局，展示所有配置分类：
- 每个卡片展示：图标 + 分类名称、配置项数量、热重载数量
- 点击卡片跳转到对应分类配置页
- 顶部：搜索框、导出按钮、导入按钮

### 2.2 分类卡片信息

| 字段 | 说明 |
|------|------|
| 图标 + 分类名称 | 如 RAG 检索 |
| 配置项数量 | 该分类下的配置项总数 |
| 热重载数量 | 支持热重载的配置项数量 |
| 点击进入 | 跳转到分类配置页 |

---

## 3. 分类配置页

### 3.1 页面布局

列表展示该分类下的所有配置项：
- 每个配置项卡片展示：中文名称、配置 Key、中文用途说明、当前值输入框、取值范围、推荐范围、影响组件、恢复默认按钮
- 顶部：筛选器（全部/热重载/需重启/已修改）
- 底部：保存所有修改、取消按钮

### 3.2 配置项卡片结构

- 中文名称 + 热重载/需重启标签
- 配置 Key（英文）
- 中文用途说明
- 当前值输入框（根据字段类型自动选择组件）
- 取值范围、推荐范围、单位
- 影响组件列表
- 恢复默认按钮

### 3.3 输入组件类型

| 配置类型 | 前端组件 |
|---------|---------|
| `float/int` 数值 | 数字输入框 |
| `bool` 布尔 | 开关组件 |
| `str` 枚举 | 下拉选择框 |
| `str` 自由文本 | 文本输入框 |
| `Dict` 字典 | JSON 编辑器 |
| `List` 列表 | 标签输入器 |

## 4. 实时校验

### 4.1 校验规则

| 校验项 | 规则 | 提示方式 |
|--------|------|---------|
| **类型校验** | 输入值必须符合字段类型（如 float） | 输入框变红 + 错误提示 |
| **范围校验** | 输入值必须在 [min_value, max_value] 之间 | 输入框变红 + 错误提示 |
| **推荐范围警告** | 输入值超出 recommended_range 但仍在合法范围 | 输入框变黄 + 警告提示 |
| **必填校验** | 配置值不能为空 | 输入框变红 + 错误提示 |

### 4.2 校验示例

当输入值超出推荐范围时：
- 输入框变黄
- 展示警告信息（如"过高可能导致 BM25 结果主导检索，降低语义匹配效果"）
- 提供操作：仍要保存、调整为推荐值

---

## 5. 影响范围展示

### 5.1 修改配置时的影响提示

用户点击保存时，弹出影响提示框：
- 列出所有修改的配置项（修改前 → 修改后）
- 每个配置项展示：影响组件、重载方式（热重载立即生效 / 冷重启需重启服务）
- 如果全部支持热重载：提示"保存后立即生效，无需重启服务"
- 如果有需重启的配置：提示"重启期间服务将短暂不可用（约 10-30 秒）"，提供"保存并重启"、"仅保存（稍后手动重启）"选项

---

## 6. 配置对比与回滚

### 6.1 配置变更对比

表格展示修改前后的差异：
- 配置项、修改前值、修改后值（未变化的标注"未变化"）
- 底部操作：保存为新版本、取消

### 6.2 配置版本回滚

表格展示版本历史：
- 选择框、版本号、修改人、描述
- 底部操作：对比选中版本、回滚到此版本

## 7. API 端点

### 7.1 配置元数据

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/config/metadata` | 获取所有配置元数据（含中文说明） |
| GET | `/api/v1/config/metadata/:category` | 获取指定分类的配置元数据 |

### 7.2 配置值

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/config/values` | 获取当前所有配置值 |
| PUT | `/api/v1/config/values` | 批量更新配置值 |
| GET | `/api/v1/config/values/:key` | 获取单个配置值 |
| PUT | `/api/v1/config/values/:key` | 更新单个配置值 |

### 7.3 配置版本

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/config/versions` | 获取配置版本历史 |
| GET | `/api/v1/config/versions/:id` | 获取指定版本详情 |
| POST | `/api/v1/config/versions/:id/rollback` | 回滚到指定版本 |
| GET | `/api/v1/config/versions/:id1/compare/:id2` | 对比两个版本 |

### 7.4 配置校验

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/v1/config/validate` | 校验配置值（不保存） |

## 8. 验收标准

| 验收项 | 标准 |
|--------|------|
| **分类展示** | 配置按功能域分组，卡片信息完整 |
| **中文说明** | 所有配置项显示中文名称和用途说明 |
| **实时校验** | 输入时实时校验类型、范围、推荐范围 |
| **影响展示** | 修改配置时展示影响组件和重载方式 |
| **版本管理** | 配置版本历史、对比、回滚功能正常 |
| **响应式** | 页面在 1280px、1920px 分辨率下正常显示 |
