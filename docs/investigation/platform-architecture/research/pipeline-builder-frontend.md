# 管道构建器前端设计调研

## 技术选型

选择 [React Flow](https://reactflow.dev/)（MIT 协议）作为画布引擎。Dify、LangFlow、RAGFlow、n8n 均使用该库，在 RAG 管道可视化编辑场景中已得到充分验证。

React Flow 提供的画布核心能力：
- 节点拖拽、连线、分组
- 缩放、小地图、对齐网格
- 撤销/重做
- 自定义节点渲染

平台自建层（约 30% 工作量）：
- 节点注册表（左侧面板，按类别分组）
- 节点参数配置面板（右侧面板，根据节点 type 动态渲染表单）
- 管道验证（连线合法性、必填参数检查、循环依赖检测）
- 管道序列化（画布 → JSON）
- 管道反序列化（JSON → 画布）
- 管道模板市场（预置模板："标准 RAG"、"高安全 RAG"、"低延迟 RAG"）

## 设计目标

- 运维人员/客户管理员通过拖拽节点构建 RAG 管道
- 不需要写代码，不需要理解底层实现
- 编辑结果导出为 JSON 管道配置，直接喂给后端引擎
- 支持保存多个版本、回滚、导入导出
