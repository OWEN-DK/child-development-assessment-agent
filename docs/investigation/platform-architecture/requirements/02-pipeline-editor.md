# 02 — 管道工作台

> **定位**：管道的全生命周期管理界面——编辑、评估、发布是同一管道的三个视图，在工作台内无缝切换。基于 React Flow 实现画布编辑。
> **与核心目标的关系**：实现 [核心目标 §四](./core-objectives.md#四管道编辑与发布可视化构建--配置输出-url) 的可视化构建、评估触发和发布配置。

## 2. 管道工作台（三视图切换）

进入管道后，顶部为工作台导航栏。编辑、评估、发布是同一管道的 3 个视图，不是独立页面。

```
┌──────────────────────────────────────────────────────────────────┐
│  ← 管道列表  │  综合问诊管道 v3  │  [编辑] [评估] [发布]              │
├──────────────────────────────────────────────────────────────────┤
│  （当前视图内容）                                                    │
└──────────────────────────────────────────────────────────────────┘
```

核心交互保留原有设计（拖拽、连线、域容器折叠/展开、条件边/降级边、复合节点、撤销/重做），详见原 [01-pipeline-model](./01-pipeline-model-and-engine.md) 节点定义。

**域容器**：
- 折叠态显示域名称 + 节点数 + 状态灯
- 展开态显示域内完整节点链
- 双击切换；域内节点不可拖到域外

**边类型**：
- 数据流边：灰色实线
- 条件边：灰色虚线 + 条件标签
- 降级边：橙色虚线 + 降级策略标签

**干运行按钮**：发送当前配置到后端编译，成功显示执行顺序，失败高亮问题节点。

**域管理**（仅聚合管道）：
- 聚合管道画布顶部有 `[+ 添加业务域]` 按钮
- 点击弹出域创建抽屉：输入域名称 + 选择知识库（下拉由 `/api/v1/knowledge-bases` 填充，自动过滤用户无权访问的库）+ 设置激活关键词
- 确认后画布上新增一个空的域容器（折叠态），同时聚合层自动添加该域对应的连接点
- 域容器的 `×` 删除按钮：删除域及其内部所有节点，确认弹窗提示"将同时移除该域的 X 个节点"
- 删除域前检查：若该域节点有边连接到聚合层节点，高亮受影响的边并二次确认

**域配置入口**：
- 双击域容器标题 → 弹出域属性面板：修改域名称、更换知识库、设置域权重、编辑激活关键词
- 更换知识库后，域内检索节点的 `knowledge_base_id` 自动更新

## 5. 性能约束与上限

| 约束项 | 上限 | 超限行为 |
|--------|------|---------|
| 单管道域数 | 20 | 创建/拖入第 21 个域容器时阻止并提示 |
| 单域内节点数 | 30 | 拖入第 31 个节点时阻止并提示 |
| 单管道总节点数 | 100 | 保存时校验，超限拒绝保存并高亮超限域 |
| 复合节点嵌套层数 | 3 | 创建第 4 层嵌套时阻止 |
| 画布缩放范围 | 25%–200% | 缩放控件限制 |
| 撤销栈深度 | 50 步 | 超出时丢弃最早的快照 |
| 管道配置 JSON 大小 | 500 KB | 保存时校验，超限提示精简配置 |
| 版本历史保留数 | 100 个版本 | 超出时自动清理最早的非发布版本（已发布版本永不清理） |

**大管道优化**：
- 域容器折叠态不渲染内部节点（仅显示域名称 + 节点数 + 状态灯），减少 DOM 节点数
- 画布使用虚拟化渲染——仅渲染视口内的节点和边
- 管道配置序列化使用增量 diff（仅保存变更部分），减少保存 payload

## 6. 验收标准

- [ ] AC-2.1：管道列表页卡片视图展示正确，管道名/版本/域数/最近评估得分/发布状态均可见
- [ ] AC-2.2：新建管道后自动进入编辑视图，画布为空（或选中模板）
- [ ] AC-2.3：编辑/评估/发布三视图通过顶部工具栏切换，切换不丢失编辑状态
- [ ] AC-2.4：从编辑视图点击"评估"→ 切换到评估视图，自动加载该管道的评估历史
- [ ] AC-2.5：从编辑视图点击"发布"→ 切换到发布视图
- [ ] AC-2.6：域内节点拖到域容器外 → 阻止并标红
- [ ] AC-2.7：聚合节点拖到域容器内 → 阻止并标红
- [ ] AC-2.8：条件边以虚线渲染，降级边以橙色虚线渲染，标签正确显示
- [ ] AC-2.9：选中节点后右侧属性面板显示该节点类型的所有可配置参数
- [ ] AC-2.10：管道保存后版本号自增
- [ ] AC-2.11：干运行结果显示编译成功/失败，失败时高亮问题节点
- [ ] AC-2.12：撤销/重做正常工作
- [ ] AC-2.13：版本对比面板高亮两个版本的节点差异和参数差异
- [ ] AC-2.14：聚合管道画布顶部显示 [+ 添加业务域] 按钮，点击弹出域创建抽屉（域名称+知识库选择+激活关键词）
- [ ] AC-2.15：域创建时知识库下拉自动过滤用户无权访问的库
- [ ] AC-2.16：删除域时二次确认，提示将同时移除的节点数
- [ ] AC-2.17：更换域的绑定知识库后，域内检索节点自动更新 knowledge_base_id
