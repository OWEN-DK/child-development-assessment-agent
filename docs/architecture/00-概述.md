## 架构总览

### 三层架构

```
Layer 1: Neo4j 知识图谱     ← AI 提炼 + 人工审核的结构化知识（跨书关系显式标注）
Layer 2: Agent 分析引擎      ← LangGraph 流水线（融合 Layer 1 + Layer 3）
Layer 3: 原文检索与待提炼回路 ← Chroma 向量索引 + LazyGraphRAG 社区树（原始文本背书）
```

### 关键设计决策

| 决策 | 说明 |
|------|------|
| **全新部署 Neo4j** | 项目未上线，无需数据迁移。Schema、索引、初始数据一次到位 |
| **LazyGraphRAG 直写 Neo4j** | 文档摄入流水线直接写入 Neo4j，不经过 MySQL 中间层 |
| **MD 工具链产出审核闭环** | AI 生成结构化 MD → 人工审核 → 入库 Neo4j，确保知识质量 |
| **特性开关** | `NEO4J_ENABLED` 环境变量控制是否启用 Neo4j 查询 |
| **降级路径** | Neo4j 不可用时各节点回退到 Chroma 向量检索 + LLM 推理 |
| **增量更新** | 已入库实体支持编辑 → Diff 预览 → 定向更新 Neo4j |

### Qwen 模型选择

> **精度优先原则**：全线使用最强模型，时间/成本可忽略。

| 用途 | 模型 | 说明 |
|------|------|------|
| 实体/关系提取 | `qwen3.7-max` | 最新旗舰，最强推理 |
| 跨书精判 | `qwen3.7-max` | 共识/互补/冲突检测 |
| Cypher 生成 | `qwen3.7-max` | NL → Cypher |
| Fallback | `qwen3.5-27b` | 当前已验证配置 |

在启动 Phase 1 之前，确认以下事项：

| 工作项 | 说明 | 状态 |

| Docker ≥ 24.0 | Neo4j 容器部署 | 需确认 |
| Python 环境 | `neo4j`、`tiktoken`、`scikit-learn`、`ebooklib`、`beautifulsoup4` 已安装 | 需确认 |

## 风险矩阵

| 风险 | 概率 | 影响 | 缓解 |
|:-----|:-----|:-----|:-----|
| Neo4j 查询性能不达标 | 低 | 高 | 提前性能测试 + 索引优化 + query timeout + 降级到 Chroma |
| AI MD 生成质量差 | 中 | 中 | few-shot prompt + 双人交叉审核 + 迭代 prompt |
| 人工审核成为瓶颈 | 高 | 中 | AI 初稿 + 审核任务优先级排序 + 批量审核模式 |
| 跨书关系标注不一致 | 中 | 中 | 标注准则 + 自动化一致性检查 |
| 现有系统改造引入回归 | 中 | 高 | 每个 Phase 独立测试 + 特性开关 + 降级路径 + 灰度上线 |
