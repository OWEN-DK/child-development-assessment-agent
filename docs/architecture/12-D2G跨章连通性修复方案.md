## 3. 业内方案调研

### 3.1 Microsoft GraphRAG

**核心思路**: chunk 级实体提取 → 全局实体 resolve → 社区检测 → 层级摘要

**实体消歧策略**:
- 提取阶段：每个 chunk 独立提取实体
- **全局 resolve 阶段**：所有 chunk 提取完后，统一做一次全局实体 resolve
  - 实体名称 + 描述的 embedding 相似度
  - 高相似度对用 LLM 做最终判定
  - 合并后的实体保留所有来源 chunk 的引用
- 社区检测：用 Leiden 算法在合并后的图上检测社区

**关键差异**: GraphRAG 的实体消歧是 **全局批量** 的，不是逐章增量的。彻底避免了 self-matching 问题。

**参考**: [microsoft/graphrag](https://github.com/microsoft/graphrag)

### 3.2 Neo4j APOC Blocking + Pairwise

**核心思路**: 用 Blocking 分桶减少比较次数，桶内两两比较。

**两阶段流程**:
1. **Blocking（分桶）**: 用 blocking key（如 entity_type + 名称前缀）把实体分到不同桶里。只有同桶内的实体才需要两两比较。
2. **Pairwise Comparison**: 桶内实体对计算相似度，超过阈值则合并。

**Blocking Key 选择**:

| Blocking Key | 原理 | 中文效果 |
|---|---|---|
| entity_type + 名称前缀 | 同类型才比较 | ⭐⭐⭐ |
| entity_type + embedding 聚类 | 同类型 + 向量近邻 | ⭐⭐⭐⭐ |
| 名称 n-gram | 字符级重叠 | ⭐⭐（中文无空格） |
| 拼音编码 | 发音相似 | ⭐⭐⭐ |

**效果**: 330 个实体，朴素比较 54,285 对 → Blocking 后 ~3,000-5,000 对 → Embedding 过滤后 ~200-500 对。

**参考**: Neo4j APOC `apoc.refactor.mergeNodes`、`gds.nodeSimilarity`

### 3.3 Union-Find 聚类

**核心思路**: 用并查集追踪实体等价类，支持传递合并（A=B, B=C → A=C）。

**两个操作**:
- `FIND(x)`: x 属于哪个组，返回组的代表元素
- `UNION(x, y)`: 把 x 和 y 所在的组合并为一组

**优势**: 比逐对 merge 更可靠——链式合并不会遗漏，最终输出的是等价类而非单次判断。

### 3.4 方案对比

| 方案 | 思路 | 优点 | 缺点 |
|------|------|------|------|
| **GraphRAG 全局 resolve** | 提取后全局批量消歧 | 彻底避免 self-matching | 需要全部提取完才能消歧 |
| **Blocking + Pairwise** | 分桶 + 两两比较 | 大幅减少比较次数 | 需要选择合适的 blocking key |
| **Union-Find 聚类** | 并查集追踪等价类 | 传递合并可靠 | 需要先有相似度判定 |
| **增量消歧（当前方案）** | 逐章入图 + 逐章消歧 | 实时上下文 | self-matching bug |
| **Staging + 全局消歧** | 先 staging 再统一消歧 | 兼顾上下文和消歧 | 需要 staging 存储 |

**结论**: 这些方案不互斥，应该**融合使用**。

#### 4.3.1 Union-Find 数据结构

```python
class UnionFind:
    """并查集：追踪实体等价类。"""
    def __init__(self):
        self.parent = {}
        self.rank = {}

    def make(self, x):
        if x not in self.parent:
            self.parent[x] = x
            self.rank[x] = 0

    def find(self, x):
        """查找根代表（路径压缩）。"""
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x, y):
        """合并两组（按秩合并）。"""
        rx, ry = self.find(x), self.find(y)
        if rx == ry:
            return
        if self.rank[rx] < self.rank[ry]:
            rx, ry = ry, rx
        self.parent[ry] = rx
        if self.rank[rx] == self.rank[ry]:
            self.rank[rx] += 1

    def clusters(self) -> dict[str, list[str]]:
        """输出所有等价类。"""
        groups = {}
        for x in self.parent:
            root = self.find(x)
            groups.setdefault(root, []).append(x)
        return groups
```

#### 4.3.2 全局消歧主函数

```python
async def batch_resolve_entities(
    staging_extractions: dict[str, ChapterExtraction],
    master: MasterGraph,
    embedding_client: EmbeddingClient,
    llm_client: LLMClient,
    model: str = "qwen-turbo",
    similarity_threshold: float = 0.85,
) -> tuple[dict[str, list[str]], list[dict]]:
    """全局消歧：两级 Blocking + Pairwise + Union-Find。
    
    Returns:
        (merge_map, merge_log)
        merge_map: {representative: [alias1, alias2, ...]}
        merge_log: [{alias, representative, similarity, reason}, ...]
    """
    # ── 收集所有实体（去重）──
    entity_pool: dict[str, ExtractedEntity] = {}  # name → 最长描述的实体
    for ch_id, ext in staging_extractions.items():
        for e in ext.entities:
            if e.name not in entity_pool or len(e.description) > len(entity_pool[e.name].description):
                entity_pool[e.name] = e
    all_entities = list(entity_pool.values())
    if not all_entities:
        return {}, []

    # ── Step 1: 两级 Blocking ──
    # Level 1: 按 entity_type 分桶
    type_buckets: dict[str, list[str]] = {}
    for e in all_entities:
        type_buckets.setdefault(e.entity_type, []).append(e.name)

    # Level 2: 全局 embedding 近邻（跨类型兜底）
    all_names = [e.name for e in all_entities]
    all_embs = await embedding_client.embed(all_names)
    emb_index = {name: emb for name, emb in zip(all_names, all_embs)}

    candidate_pairs: set[tuple[str, str]] = set()

    # Level 1: 类型内 pairwise
    for etype, bucket in type_buckets.items():
        if len(bucket) < 2:
            continue
        for i in range(len(bucket)):
            for j in range(i + 1, len(bucket)):
                sim = _cosine_similarity(emb_index[bucket[i]], emb_index[bucket[j]])
                if sim >= similarity_threshold * 0.9:
                    candidate_pairs.add(tuple(sorted([bucket[i], bucket[j]])))

    # Level 2: 全局 top-k 近邻（跨类型）
    for i, name in enumerate(all_names):
        sims = [(j, _cosine_similarity(all_embs[i], all_embs[j]))
                for j in range(len(all_names)) if j != i]
        sims.sort(key=lambda x: x[1], reverse=True)
        for j, sim in sims[:10]:  # top-10
            if sim >= similarity_threshold * 0.9:
                candidate_pairs.add(tuple(sorted([all_names[i], all_names[j]])))

    # ── Step 2: LLM 判定 + Step 3: Union-Find 合并 ──
    uf = UnionFind()
    for name in all_names:
        uf.make(name)

    entity_desc = {e.name: e.description for e in all_entities}
    merge_log = []

    for name_a, name_b in candidate_pairs:
        try:
            judgment = await llm_client.generate_structured(
                prompt=SAME_ENTITY_PROMPT.format(
                    name_a=name_a, desc_a=entity_desc.get(name_a, ""),
                    name_b=name_b, desc_b=entity_desc.get(name_b, ""),
                ),
                schema=EntityMatchJudgment,
                model=model,
            )
            if isinstance(judgment, EntityMatchJudgment) and judgment.same:
                sim = _cosine_similarity(emb_index[name_a], emb_index[name_b])
                uf.union(name_a, name_b)
                merge_log.append({
                    "alias": name_b, "representative": name_a,
                    "similarity": round(sim, 3), "reason": judgment.reason,
                })
                logger.info("消歧合并: '%s' ↔ '%s' (sim=%.2f, reason=%s)",
                            name_a, name_b, sim, judgment.reason)
        except Exception as e:
            logger.warning("消歧 LLM 判定失败: %s ↔ %s: %s", name_a, name_b, e)

    # ── Step 4: 代表选举（描述最长的为代表）──
    clusters = uf.clusters()
    merge_map = {}  # alias → representative
    for root, members in clusters.items():
        representative = max(members, key=lambda n: len(entity_desc.get(n, "")))
        for m in members:
            merge_map[m] = representative

    # ── Step 5: 消歧后入图 ──
    for ch_id, ext in staging_extractions.items():
        # 设置段落总数（审查修正: 必须设置 chapter_para_count）
        para_count = max(
            (pid for e in ext.entities for pid in e.source_para_ids),
            default=0,
        )
        master.chapter_para_count[ch_id] = para_count

        for entity in ext.entities:
            rep = merge_map.get(entity.name, entity.name)
            master.add_entity(
                ExtractedEntity(
                    name=rep, entity_type=entity.entity_type,
                    description=entity.description,
                    source_para_ids=entity.source_para_ids,
                ),
                ch_id,
            )

        for rel in ext.relationships:
            mapped = ExtractedRelationship(
                source=merge_map.get(rel.source, rel.source),
                target=merge_map.get(rel.target, rel.target),
                relation_type=rel.relation_type,
                evidence=rel.evidence,
                source_para_ids=rel.source_para_ids,
                relation_source=rel.relation_source,
                confidence=rel.confidence,
            )
            master.add_relationship(mapped, ch_id)

    logger.info(
        "全局消歧完成: %d 实体 → %d 簇, %d 次合并",
        len(all_entities), len(clusters), len(merge_log),
    )
    return merge_map, merge_log
```

### 🔴 审查 3: Blocking 仅按 entity_type 分桶，跨类型实体无法比较

**问题**: 方案 §4.3.2 Step 1 只按 `entity_type` 分桶。如果同一个概念在不同章节被标注为不同类型（很常见），它们永远不会被比较：

```
ch01: "运动"       → entity_type = Exercise
ch02: "体育锻炼"   → entity_type = Concept      ← 不同类型！
ch03: "体能训练"   → entity_type = Strategy     ← 不同类型！
```

这三个实体分属三个不同的桶，永远无法合并。

**修正**: 采用 **两级 Blocking**：

```
Level 1: 按 entity_type 分桶（同类型优先比较）
Level 2: 跨类型兜底 — 对每个实体取 embedding，在全局 embedding 索引中找 top-k 近邻
```

```python
# 两级 Blocking
async def block_entities(entities, embedding_client, top_k=10):
    # Level 1: 类型内桶
    type_buckets = group_by_type(entities)
    
    # Level 2: 全局 embedding 近邻（跨类型兜底）
    all_names = [e.name for e in entities]
    all_embs = await embedding_client.embed(all_names)
    
    candidates = set()
    for i, emb in enumerate(all_embs):
        # 计算与所有实体的相似度，取 top-k
        sims = [(j, cosine(emb, all_embs[j])) for j in range(len(all_embs))]
        sims.sort(key=lambda x: x[1], reverse=True)
        for j, sim in sims[1:top_k+1]:  # 排除自身
            if sim >= 0.76:
                pair = tuple(sorted([all_names[i], all_names[j]]))
                candidates.add(pair)
    
    return candidates
```

**成本**: 330 个实体的全局 embedding 已在 Step 2 计算，top-k 检索是 O(n²) 但 n=330 可接受。
