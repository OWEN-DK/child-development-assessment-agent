# Checklist

- [ ] `settings.py` 中的所有配置项均已添加 `description` 描述信息。
- [ ] `GET /api/v1/config` 能正确返回配置列表、类型、默认值、当前值和描述信息。
- [ ] `PUT /api/v1/config` 能够更新内存配置并持久化，且不需要重启后端服务即可在后续请求中生效。
- [ ] 提供了恢复默认值（回退至 `.env.dev`）的后端接口或逻辑。
- [ ] 前端成功集成了全新的“系统配置”页面，能按类别展示和修改所有配置，并能清晰展示每个配置的作用说明。
- [ ] 回撤测试（评估）页面包含了动态调优面板，可以在该面板中修改配置。
- [ ] 在调优面板中修改配置并触发“重新测试”后，后端能使用新的配置完成测试，并在前端展示对比结果。
- [ ] 重启后端服务后，已保存的自定义配置不会丢失。
