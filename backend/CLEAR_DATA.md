# 清空索引和历史记录

## 使用方法

在 backend 目录下运行以下命令：

```bash
uv run python clear_index_and_history.py
```

## 清空内容

该脚本会清空以下内容：

1. **Chroma 数据库** - 删除所有向量集合
2. **Llama Index 存储** - 删除索引存储目录 (`./storage`)
3. **文档管理器** - 删除所有文档注册记录
4. **导入任务历史** - 删除所有任务状态文件 (`./data/import_tasks/*.json`)
5. **临时上传文件** - 删除临时上传目录中的文件 (`./temp_uploads/*`)

## 清空后的状态

清空完成后，系统会回到初始状态，可以重新导入新的文档数据。

## 验证清空结果

运行以下命令验证 Chroma 数据库已清空：

```bash
uv run python check_chroma.py
```

应该显示：`集合数量：0`

## 注意事项

- 此操作不可逆，请确保已备份重要数据
- 清空后需要重新上传文档才能使用 RAG 功能
- 建议在导入新数据前执行此操作，避免数据冲突
